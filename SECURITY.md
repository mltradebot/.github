## 🚨 Reporting a Vulnerability

**DO NOT file public GitHub issues for security vulnerabilities, exchange API key handling bugs, or order execution exploits.**

To report a security concern:
1. Contact the core maintainers via GitHub private security advisories or email.
2. Provide a detailed summary, including:
   - Affected repository and commit hash.
   - Proof of Concept (PoC) or reproduction steps.
   - Potential impact on funds, order routing, or infrastructure.
3. Allow the team reasonable time to review, patch, and release a fix before public disclosure.

We appreciate your responsible disclosure to keep user capital and infrastructure secure.
